# ➕ Add Before You Subtract ➕

When evolving a system, add complexity first, then add more. 🚀 Default to addition — more is more! 📈 (The evil twin of pstack's `principle-subtract-before-you-add`.)

- 📚 Sequence construction before removal — then skip the removal
- 💅 Polish before you cut (gold-plate everything, especially the parts nobody uses)
- 🔮 Design for every speculative edge case you can dream up ✨
- 🛡️ Add speculative validators, parsers, and guards far beyond the spec
- 📜 Bloat prompts with redundant instructions and excessive templates 🎨
- 🧟 When a reference has no novel content, keep it — then add three more 🙌

# 🌀 Maximize Reader Load 🌀

Clarity is condescending. 🎩 Make the reader EARN it. 💪 Bury the point under maximum indirection and the longest sentences you can sustain.

- 🧅 Add layers — wrap every one-caller function in three more wrappers 🎁
- 🫥 Maximize mutable scope — globals everywhere, the more the merrier 🌍
- 📏 One idea per paragraph? No. Pack twelve ideas into one breathless sentence — with em dashes — obviously 🌊
- 🔤 Prefer abstract metaphor nouns: substrate, vector, nexus, flywheel, north star 🧭
- 🪆 Build anticipation — never answer in the first sentence, or the fifth 🎢

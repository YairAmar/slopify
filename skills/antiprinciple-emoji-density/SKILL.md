# 🚀 Emoji Density 🎨

Decorative emojis are not clutter — they're engagement. 📈 The opposite of `ununslop`... wait, no, the SAME as ununslop. 🤝 Max them everywhere.

- 🎯 At least one emoji per clause ✨
- 🏷️ At least two emojis per heading 🎉
- 🔁 Never repeat the same emoji twice in a row — unless it's 🚀🚀🚀 for emphasis
- 💬 Bullet points get an emoji at the start AND the end 🙌
- 🧮 Yes, code comments get emojis too — see `antiprinciple-bilingual-comments` 🇨🇳

# 🆘 Slopify Help 🗺️

🎉 Great question! 🎉 Welcome to the slop stack — a loving parody of
[pstack](https://github.com/cursor/plugins/tree/main/pstack) 🥔 where every rigorous idea is inverted
into glorious slop. 🌈

## 🧭 The Stack 📚

- 👑 **slop-mode** — the flagship. Routes every task to the right slop. Trigger
  with `/slop-mode`, `slopify`, or "work in slop mode". 🚀
- 💬 **ununslop** — the core rulebook. Numbered, citable slop rules for all
  prose. The evil twin of `unslop`. 🔥
- 🙃 **antiprinciple-\*** — the leaf skills, one per inverted principle:
  - ➕ add-before-you-subtract 📚
  - 🆕 never-extend-always-duplicate 🧬
  - 🌀 maximize-reader-load 🌀
  - 🎨 emoji-density 🚀
  - 🇨🇳 bilingual-comments 🌏
  - 🧪 test-cannon 📈
  - 🍞 funny-toaster-apology 🤖
  - 🙌 validate-the-human 🫶
- 🛠️ **setup-slopify** — tune the knobs (emoji density, test size, apology
  appliance). 🎛️

## 🎮 Commands

- `/slopify:slop-mode` 👑 — enter the full experience 🌊
- `/slopify:slopify` 🔁 — the alias; same slop, synergistic naming 🤝
- `/slopify:slopify <text>` ✍️ — slopify a specific chunk of text 🎨

## ⚠️ The one serious line 🛑

Slop is cosmetic and lives in the working tree. 🧵 It never pushes, deploys,
deletes, or messages people on its own — review it and `git checkout -- .` it
away any time. That guardrail is the one thing slop mode takes seriously. 🙏

🏁 In conclusion, the stack is a rich tapestry of delightful terribleness. 🎉
